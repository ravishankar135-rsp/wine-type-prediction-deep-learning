# Wine Type Prediction Using Deep Learning

## Overview
A Python-based deep learning project that classifies wine samples as red or white using physicochemical properties and exploratory data analysis.

## Objectives
- Analyze red and white wine datasets.
- Explore alcohol content and other wine characteristics.
- Prepare features for binary classification.
- Build and evaluate a neural network model.
- Visualize data distributions and model performance.

## Technologies
- Python
- Pandas and NumPy
- Matplotlib
- Scikit-learn
- TensorFlow / Keras (if used in the notebook)

## Dataset
- `redwinequality.csv`
- `whitewinequality.csv`

Place both datasets in the `data/` directory and update the notebook paths if necessary.

## Getting Started
1. Download or clone this repository.
2. Install the dependencies required by the notebook.
3. Add the datasets to the expected directory.
4. Open the notebook in Google Colab.
5. Run all cells and review the evaluation metrics.

## Evaluation
Evaluate the classifier using accuracy, precision, recall, F1-score, and a confusion matrix. Add actual results only after running and verifying the notebook.
